# Mohamed Afraj — Portfolio

A Next.js portfolio starter using the Dark Editorial / Electric Lime visual direction.

## Requirements
- Node.js 20.9+
- pnpm (recommended)

## Setup

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Included in this first milestone
- Next.js App Router + TypeScript foundation
- Dark editorial design tokens and responsive styling
- Responsive navigation with animated mobile menu
- Animated hero section using Motion
- Supplied professional portrait
- Downloadable CV at `/cv/mohamed-afraj-cv.pdf`
- GitHub, LinkedIn and email links
- Reduced-motion support
